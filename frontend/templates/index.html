STUDENT QUANTITATIVE GUIDE: UNDERSTANDING ML METRICS ACADEMIC AUDIT
Out-of-Sample Accuracy: Evaluated strictly on unseen future test bars ($t > t_{\text{split}}$). Unlike in-sample training accuracy, out-of-sample accuracy measures real generalization.
Majority-Class Baseline: The accuracy achieved by naively predicting whichever class occurred most often in the training set. A model is only valuable if its test accuracy exceeds this threshold.
Class Probability vs Accuracy: Class probability $P(\text{Up})$ is the model's internal score distribution on the latest bar. It is NOT a win rate guarantee and should never be confused with test accuracy.
Chronological Splitting: Financial markets possess temporal autocorrelation. Shuffling or standard $k$-fold cross-validation causes future-to-past data leakage. We enforce strict chronological partitioning.
DISCLAIMER: Probabilistic mathematical model for academic evaluation. Past accuracy is no guarantee of future returns.
